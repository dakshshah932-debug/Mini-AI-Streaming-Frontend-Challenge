# Mini AI Streaming Frontend

A modern frontend application built with Vite and React that integrates with AI APIs to fetch real-time data and display outputs as interactive streams. This project demonstrates seamless API integration, dynamic rendering, and a user-friendly interface for AI-driven results.

## Features

- **Real-time AI Integration:** Fetches responses from AI APIs dynamically.
- **Streaming Output Display:** Displays AI outputs in live, interactive streams.
- **Responsive UI:** Built with Tailwind CSS for mobile-friendly and clean design.
- **Customizable Components:** Modular design for easy updates and expansions.
- **Light/Dark Mode Support:** Adaptable themes for improved user experience.

## Technologies Used

- **Frontend:** React, Vite, JavaScript
- **Styling:** Tailwind CSS
- **UI Components:** Flowbite (optional, for dropdowns and interactive elements)
- **API Integration:** Fetch API or Axios
- **Optional:** React Router, Zustand, or Context API for state management
